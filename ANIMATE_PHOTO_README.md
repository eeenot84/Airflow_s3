# Анимация фото с аудио

Скрипт для создания анимированного видео из фотографии с добавлением звукового сообщения.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование

### Базовое использование:
```bash
python animate_photo.py путь/к/фото.jpg
```

### С указанием выходного файла:
```bash
python animate_photo.py фото.jpg выходное_видео.mp4
```

## Что делает скрипт:

1. **Анимация фото**:
   - Эффект плавного увеличения (zoom)
   - Эффект изменения яркости и контраста
   - Плавные переходы между кадрами

2. **Добавление аудио**:
   - Генерирует речь из текста "У меня все хорошо. Всем привет!"
   - Синхронизирует длительность видео с аудио

3. **Результат**:
   - Создает MP4 видео файл с анимированным фото и звуком

## Примеры:

```bash
# Обработать фото и сохранить как photo_animated.mp4
python animate_photo.py photo.jpg

# Указать имя выходного файла
python animate_photo.py photo.jpg my_video.mp4

# С полным путем
python animate_photo.py /path/to/image.jpg /path/to/output.mp4
```

## Требования:

- Python 3.9+
- FFmpeg (для обработки видео)
- Интернет-соединение (для генерации речи через gTTS)

## Примечания:

- Скрипт автоматически создаст имя выходного файла, если оно не указано
- Поддерживаются форматы изображений: JPG, PNG, GIF, BMP
- Выходное видео будет в формате MP4 с кодеком H.264
